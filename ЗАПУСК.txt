Travel Ready — текущий исходный проект для Windows

Для работы нужна локальная установка SQL Server Express LocalDB либо другой
доступный SQL Server. По умолчанию приложение подключается с учётной записью
Windows к экземпляру (localdb)\MSSQLLocalDB и создаёт базу TravelReadyDb.
Если экземпляр остановлен, запустите его командой:
    sqllocaldb start MSSQLLocalDB
Имя сервера и базы можно переопределить переменными TRAVELREADY_SQL_SERVER и
TRAVELREADY_DATABASE_NAME. У пользователя должны быть права создать базу.
Автономный EXE включает .NET, но не устанавливает SQL Server LocalDB.

Откройте TravelReady.sln в этом каталоге через Visual Studio 2022
или запустите текущий исходный проект командой:
    dotnet run --project TravelReady/TravelReady.csproj -c Release

Новый интерфейс — светлый двухстраничный разворот: слева маршрут, шаблоны,
готовность и погода, справа список вещей. Палитра — сиреневый фон, сливовый
и коралловый акценты; заголовки набраны Georgia, рабочие поля — Arial.

При первом запуске создайте профиль. Для регистрации и кнопки «Забыли пароль?»
нужен отдельный работающий Mail API с настроенным SMTP. В форме входа откройте
«НАСТРОИТЬ ПОЧТУ / MAIL API» и укажите адрес API и токен. Удалённый API
должен работать по HTTPS; HTTP допускается только для loopback. Токен
сохраняется через Windows DPAPI, SMTP-пароль остаётся на почтовом сервере;
в приложение и исходники секреты не встроены. Реальная SMTP-доставка в
этом прогоне не проверялась — проверьте её отдельно на своём почтовом ящике.

При наличии прежней %LOCALAPPDATA%\TravelReady\travelready.db приложение
переносит данные из SQLite в пустую SQL-базу. Исходный SQLite-файл остаётся
без изменений; новые данные сохраняются в SQL Server.

Для прогноза можно указать личный ключ WeatherAPI через «КЛЮЧ API»;
он защищается DPAPI отдельно от программы. Без ключа используется Open-Meteo.
Остальные проверки и результаты описаны в TESTING.md.
